# GTA V GARAGE

**GTA V GARAGE** - универсальный конфигуратор графики для **Grand Theft Auto V** (Legacy и Enhanced). Тёмная тема, готовые пресеты, поддержка RAGE MP и alt:V, а также фишка программы - отключение теней, травы, воды и частиц через нестандартные значения `settings.xml`.

## Возможности

### Поддержка обеих версий игры
- **Legacy** и **Enhanced** - программа сама находит обе версии в папке `Документы\Rockstar Games`.
- Цветовые индикаторы (зелёный/красный) показывают, какая версия установлена.
- Отдельные таблицы значений для каждой версии - ничего не путается.

### Готовые пресеты
- **Экстремальный** - минимум графики, максимум FPS.
- **Низкий** - базовые текстуры, отключены тени и трава.
- **Средний** - сбалансированный вариант.
- **Высокий** - хорошая графика при стабильном FPS.
- **Ультра** - максимум качества.
- **Пользовательский** - всё вручную.

### Полный контроль над настройками
- 11 ComboBox'ов качества: тени, текстуры, отражения, трава, вода, частицы, пост-обработка, шейдеры, анизотропка, MSAA, затенение AO.
- 5 параметров экрана: разрешение, частота, формат (16:9 / 16:10 / 4:3 / 5:4 / 3:2), режим (окно / полный / без рамки), DirectX.
- 7 слайдеров: масштаб рендера, дальность прорисовки, детализация теней, мягкие тени, детализация пешеходов и машин.
- 17 чекбоксов: FXAA, Motion Blur, тесселяция, VSync, скрытые параметры, Read-Only.

### Enhanced-специфичные настройки
- **Сглаживание (AAType):** Выкл / FXAA / TAA.
- **Затенение (SSAOType):** Выкл / HBAO / SSDO.
- **Качество освещения:** Стандарт / Высокое / Очень высокое / Сверхвысокое.
- **Генератор кадров:** Выкл / AMD FSR 3.
- **Масштабирование:** Выкл / AMD FSR 3 / AMD FSR 1 / Выборка.
- **NVIDIA Reflex:** Вкл / Выкл.
- **Трассировка лучей:** Вкл / Выкл (только для RTX-карт).
- **RT Отражения:** Вкл / Выкл.

### Информация о железе
- **CPU:** WMI -> реестр -> переменная окружения (тройная защита).
- **GPU:** WMI с корректным VRAM (4, 6, 8+ ГБ).
- **RAM:** объём, тип DDR (DDR3 / DDR4 / DDR5), частота.
- **Автоподстановка** реального CPU/GPU в `settings.xml`.

### Сохранение и загрузка
- Все настройки читаются из `settings.xml` при старте.
- Правильная структура XML - как в оригинале игры.
- Удаление мусорных ключей (`MSAAFragments`, `RunningMode` и т.д.).
- **Read-Only** - защита файла от перезаписи игрой.

### Интерфейс
- Тёмная тема в стиле GTA V с оранжевыми акцентами.
- Кастомные элементы управления: ComboBox, CheckBox, Slider, RadioButton.
- Подсказки для каждого параметра.
- Безрамочное окно можно двигать за любое место.

## Системные требования

- **ОС:** Windows 10 / 11 (64-bit)
- **.NET Framework:** 4.7.2 или выше
- **Игра:** Grand Theft Auto V (Legacy или Enhanced)

## Установка

1. Скачай последний релиз из раздела **Releases**.
2. Распакуй архив в любую папку.
3. Запусти `GTAGARAGE.exe`.
4. Программа автоматически определит установленную версию игры.
5. Настрой графику и нажми **«Сохранить»**.

Важно: игра должна быть **закрыта** во время сохранения настроек.

---

## Известные ограничения

- **Enhanced требует DirectX 12** - на старых видеокартах может не запуститься.
- **RAGE MP Enhanced** - всё ещё в статусе публичной беты. Краши могут быть не из-за программы.
- **32:9 не поддерживается** нативно GTA V - используйте сторонние моды.
- **DLSS** недоступен на GTX 1050 Ti и старых картах - в меню показывается только FSR.

# Changelog

Все значимые изменения проекта документируются в этом файле.

## [0.5.0-beta] — 2026-09-17

### Added
- Поддержка **`SamplingMode`** (Legacy) — управление масштабом разрешения из программы.
- Поддержка **`MaxLodScale`** (Legacy) — управление расстоянием подгрузки детализированных объектов.
- Дискретные слайдеры с метками (`Выкл`, `x0.5`, `0`, `0.1`, …, `1.0`).
- Тултипы на подписях настроек (объясняют, что делает параметр).

### Fixed
- **«Масштаб разрешения»** теперь реально влияет на FPS (ранее писался мёртвый ключ `RenderScale`).
- **«Расстояние подгрузки»** корректно мапится на дискретные значения игры.
- **Трава** — «Отключено» больше не превращается в «Сверхвысок.».
- **Двойная загрузка** настроек при старте программы.
- **`LegacyOnlyPanel`** корректно скрывается в Enhanced.
- **`RenderScalePanel`** корректно скрывается в Enhanced.
- **Enhanced XML** — убраны лишние ключи, исправлены дефолты.
- **Тултипы** — больше не перекрывают UI.

### Removed
- Мёртвый ключ **`RenderScale`** из Legacy и Enhanced.
- Значение **`-0.3`** из `MaxLodScale` (не работало).

### Changed
- **`numReplayBlocks`** (Enhanced) → `36` (соответствует эталону).
- **`Shader_SSA`** (Enhanced) → читается из XML (дефолт `false`).
- **Все боксы слайдеров** — одинаковая ширина (55px).
- **«Выкл.»** → **«Выкл»** (без точки).

### Known Issues
- `commandline.txt` не заполняется автоматически.
- Чекбоксы `CheckPostFX`, `CheckSkipIntro`, `CheckNoPrecache`, `CheckHdStreaming` — не привязаны к XML.
- `DetectCurrentPreset` может ошибаться для Enhanced.
- `pc_settings.bin` не парсится.
